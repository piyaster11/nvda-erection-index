How it’s calculated

The score is the equal-weight average of five indicators, each scaled to 0–100, using NVIDIA’s daily prices. Nothing is invented, and no options, news, or social-media data go into it.

  • Price vs 125-day moving average — percent distance from the 125-session average, mapped with a smooth (tanh) scale where a 20% gap is a strong reading.
  • 14-day RSI — Wilder’s relative strength index, used directly as a 0–100 sub-score.
  • 52-week high / low — where the close sits between the 52-week high and low (252 sessions of daily highs and lows).
  • 20-day vs 1-year volatility — inverted: short-term volatility above its one-year average scores lower (fear); a calmer tape scores higher.
  • 5 / 20-day return — the average of five-session and twenty-session price changes, each tanh-mapped.

Zones follow the usual Fear & Greed bins: 0–24 Limp / Extreme Fear, 25–44 Half-mast / Fear, 45–55 Neutral, 56–75 Rising / Greed, 76–100 Rock Hard / Extreme Greed.

A GitHub Action recomputes docs/data/index.json on weekdays after the U.S. close, and the page loads that file so it works without a Yahoo request in the browser (those are usually blocked by CORS). Add ?live=1 to try a live recompute with the same formulas.
